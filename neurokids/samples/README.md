# Sample slices

Four contiguous axial head CT slices (0.7 mm apart) with ventricle labels, copied from
[fast-radiology/hydrocephalus](https://github.com/fast-radiology/hydrocephalus) `data/` (MIT licence, © 2019 fast-radiology).
That repository repeats these slices under several patient folders; these are the unique ones.

- `ct/` – CT slices (DICOM, Hounsfield units)
- `label/` – matching masks (DICOM, 0 = background, 1 = ventricular CSF)
