Interfacing with

CODE ICH

Intracerebral and subarachnoid hemorrhage share the same first problem: finding and measuring blood on a head CT, fast and the same way everywhere. SAHVERA is designed to interface with the CODE ICH group so that volumetric measurement, AI tools and trial-ready data standards can be shared across hemorrhagic stroke.

  • Common hemorrhage volumetrics and reporting language
  • Shared imaging pipelines and AI validation approaches
  • Aligned governance for multi-site, de-identified data
